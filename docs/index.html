Engine Comparison
Rules

v16 (mainnet today) follows monero-project/monero master (src/cryptonote_core/blockchain.cpp, cryptonote_basic_impl.cpp). v17 (the FCMP++ hard fork) follows the seraphis-migration/monero branch fcmp++-stage, which implements ArticMine's MoneroScaling2026-03. Block weights, medians and the long-term clamp are integers computed the way blockchain.cpp computes them.

  • The 2026 spec rescales pre-fork block weights by 625/300 when the medians span the fork. The reference code does not do this, and neither does this simulator.
  • The long-term median can rise at most about 1.2x per 50,000 blocks (half the window) under v17, and about 1.7x under v16.
